# 外汇和债券投研分析

来源是投资大脑《问题案例驱动外汇和债券投资》精简使用包（2026-10-05 整理）。分析框架、取数方法、计算口径和历史案例已全部收进本技能，本技能独立可用。能读到原包时可以回查题库和原卡，两边冲突以本技能为准。

本技能分前台和后台。后台是第 0 到第 6 节，用来思考和打底稿，要用足。前台是第 7 节，交给用户的只有判断清楚的报告和几张图，后台的术语、编号和表格一律不出现。

---

## 0. 主轴：一个拆分，三个问题

任何利率或汇率价格都拆成两块：**价格 = 市场预期的政策利率路径 + 风险补偿。**

- **债券**：长端收益率 = 预期名义短率的期限平均 + 期限溢价。预期名义短率已经含通胀，再拆通胀时不重复相加。长短利差不等于期限溢价。
- **外汇**：利率平价长期不成立，套息长期有正收益，说明汇率里也有一块随时间变的风险补偿。仓位、对冲比例、避险需求、融资压力和官方干预都在这一块。

所有追问都落到三个问题上：

1. **动的是哪一块？** 是政策路径被重新定价，还是风险补偿变了（期限溢价、仓位、买家、避险、融资）。
2. **谁在边际承担这份风险，他还能、还愿意承担多久？** 买家、杠杆、仓位、对冲比例、当局和制度都在这一问。它们常常就是推动价格的那只手，不只决定行情能持续多久。
3. **在这个价格持有，账算得过来吗？** 市场已经计入了多少，我的判断和它差多少；carry、对冲后收益和盈亏平衡还剩多厚。

三条前提：

- **三个问题分开答。** 第一问答对，不等于第三问能赚钱。看对加息却在日元上亏钱、看对降息却在长债上亏钱，都是把第一问的答案当成了第三问的答案。
- **同步不是因果。** 利差和汇率一起动，只说明"政策预期"值得当候选解释；曲线变陡变平，只说明问题出在哪段。每一段因果都要有独立证据：事件前后的时间顺序、持仓和流量、拍卖和买家、官方原文。
- **这类判断算不出概率。** 阈值、窗口和情景是防止自己乱来的纪律，不是算出来的胜率。案例数量不能换算成胜率，情景不填未经校准的概率。

能力边界：本框架擅长拆清价格为什么动、市场计入了什么、这个价位值不值。它不预测点位，也没有被证明能提前判断转折。以外汇和主权债为核心；信用债、含权债和复杂衍生品要另补发行人信用、条款和专用定价。

## 1. 干活的顺序

1. **锁范围。** 底稿开头写清以下几项，缺的写"待补"，不要猜：
   - **主问题**：一句话写清读者看完要解决什么。"消息范围缩小，为何超长端还涨"比"存款降息对债市的影响"更能决定要搜什么、算什么。
   - **任务类型**：解释已发生的事、判断接下来、比较方案、银行配置约束，四选一。不要把一篇评论升级成交易建议。
   - **资产与期限**：哪个货币对、哪个国家、哪段期限。跨币种问题两边都看。
   - **截止时点**：日期、时刻、时区；报价是日终、盘中还是固定期限口径。
   - **损益口径**：只在涉及损益时写，包括记账币种、报价方向、持有期、融资方式和对冲比例。缺报价方向、记账币种或持有期时，不先算净收益。
   - **档位**。
2. **定档位。** 用户说过"快速""简短"或"深度""做细"，就照办。没说时用一句话问一次；问了没有回答，或者用户不在场，按快速做。以下情况才走深度：用户明确要求；要做实际配置或调整对冲比例；快速档的证据给出相反信号；出现干预、制度变化或市场功能异常。快速和深度的研究质量要求相同，只是篇幅不同。
3. **先问后找。** 按第 2 节追问，按第 3 节取数。先确认今天的日期和时区。凡是"现在"的事实，比如汇率、收益率、定价、最新数据、拍卖和表态，都先查再说，并记下查询时刻。取数顺序是：官方原文 → 官方收益率和统计 → 市场定价和模型 → 卖方和媒体（只当线索）。官方的历史文件和当月文件可能分开发布，不能假设历史文件已含本月数据。
4. **计算一律跑代码**（第 5 节）。
5. **对照历史**（第 6 节）：先选机制，再看结果。
6. **过反问关，换一双眼睛**（第 2 节）。
7. **写报告并自查**（第 7 节）。
8. **留档、清理。** 重要判断按第 8 节留档。交付后清理工作目录里的底稿、临时脚本和图表草稿。

**银行资金部默认口径**（用户没有指定用途时适用）：

- 美国国债只作政策与利率参照，用户没有明确允许时不当作可直接投资的品种。美元债配置写可投的离岸美元债。"日本市场美元债"是错误写法，只有讨论日本境内发行、挂牌或交易制度时才用"日本市场"。
- 不固定设"对我们"一节，不分析用户不做的方案（比如日元资金对冲后买美债）。用户明确要求比较时，只比实际允许的选择。
- 组合本来以短久期和浮息债为主时，不写"需要马上转向防守"，写组合已有准备，后续重点防信用利差和二级流动性。
- 没有本行实际参数（边际资金转移定价、限额、现有敞口）时，只分析市场和单位风险，不判断本行能承担多少，不给额度或精确的对冲比例。公开市场利率只作参考，不冒充本行成本。
- 语气是研究结论，不是交易指令：写"可优先选择短久期、浮动利率、高评级、成交活跃的离岸美元债"。不自动下单，不替用户定仓位。

## 2. 追问心法（后台）

**第零步：先追问问题本身。**

- **核对问题里预设的事实。** 问"为什么超长端还在涨"，先确认它确实在涨：哪段时间、哪个期限、什么口径。预设不成立，就直接告诉用户，改成对的问题再研究。
- **把模糊词改成可检验的定义。** "见顶"改成"未来三个月 10 年期不再创新高"；"持续"改成"一个月后仍在原方向，且利差同向"；"值得"改成"扣完融资和对冲后，比持有现金或短券多多少"。
- **问清这个问题服务什么决定。**
- **写下自己此刻的第一判断，以及它从哪来。** 来自数据、上一份报告、提问的语气，还是流行说法。来源越弱，后面越要重点戳它。

**第一步：找出三到五个核心方面。** 用主轴三问给这次问题各过一句话，挑出对结论最关键、证据最没把握、分歧最大的几项，再翻译成这个市场这段时间自己的语言。下面的示例是虚构情形：

- 不写"预期差"，写"美日两年利差一周只动了 2 个基点，美元兑日元却跌了 5%，差的那部分是谁在买日元"；
- 不写"边际买家"，写"日本银行每月少买 2,000 亿日元以后，20 年以上那段由谁来接"；
- 不写"已计价"，写"OIS 已给下次会议计入几成加息，落地还剩多少意外"。

检验方法：把货币、国家或期限换掉，这句话还成立，就是太泛，要重写。再从中挑出最脆的一两个方面，即证据最薄、一旦错了结论就翻的那个，作为全篇主线。

**第二步：每个方面往下追问，问到能用事实回答为止。**

- **一层一层剥。** 每到一层，先问"这一层的底层事实是什么，结论靠什么撑着"，再往下走一层。方向沿着因果链：价格 → 哪一块在动 → 谁在承担 → 约束和持续性 → 已计价 → 持有期结果。
- **至少摆出两个解释，只找能把它们分开的证据。** 例子：解释 A 是"日本银行加息，日元走强"，解释 B 是"美国数据转弱，美元自己在跌"。如果 A 对，应当看到日本两年期先动，日元对欧元、澳元也一起涨；如果 B 对，应当看到美国两年期先动，欧元兑美元同样涨。两个解释都说得通的证据，再多也不加分。
- **量级要对得上。** 每条因果都问一次"够不够大"：新增买盘和这段曲线的 DV01 比是多少；利差变动按近期 beta 能解释几成汇率变动；负债成本下降作用在多大余额上。方向对、量级差一大截的，只能算次要原因。
- **站到交易对手的位置。** 问以这个价格做反方向的是谁：守负债久期的寿险、被限额逼着卖的银行，还是止损的投机盘？他看到了什么你没看到的？说不出对手是谁，就还没看懂这个价格。
- **每一问都配取证。** 自问自答不算数。取不到的数据，直接记成缺口，不在推理里绕圈子。
- **问到一个数字、一份文件或一件可观察的事，这一支才算到底。** "日元会不会继续涨"没问到底，"CFTC 日元净空头还剩多少、比上周减了多少、两年利差同期变了多少"才算。
- **反问关。** 主线成形时，假设结论是错的，问最可能错在哪：是不是把头寸调整当成了政策重估，把季末资金摩擦当成了趋势，把一次拍卖当成了需求见顶。能用同一组事实构造出更简单的解释，就要正面回应它。
- **"凭什么"连问三次。** 每个关键判断要经得住连续三次追问"凭什么"，每次都落到可核查的事实上。落不到，就重做或删掉。
- **换一双眼睛。** 能调用子代理或另一个模型时，只给它结论、关键证据和数字，让它专门找最弱的一环。没有这个条件时，就以反方身份从结论倒着重读一遍。
- **答案不再改变判断，就停。** 连续两轮补料仍解决不了决定性缺口时，交付有边界的阶段性判断，写明最多三项最关键的待补数据。
- **留下可观察推论。** 主线定下后，写两三条近期就能看到的验证点：哪天的数据、哪次拍卖、哪个价差到哪里。这些进第 8 节留档。

**第三步：把追问树拉直成一条叙述线。** 排出读者需要知道这些事实的先后顺序，这条线就是报告骨架。不在主线上、已经站住的方面，压成一句前提嵌进相关段落；和本题无关的方面，正文不提。不为了"完整"把三问各讲一遍。

**底稿卡**（每个核心方面一张，只给自己看）：

```
【方面｜用这个市场自己的语言｜对应三问中的哪一问】
问题本身：预设核对了吗｜关键词怎么定义
竞争解释：A｜B，各自还应看到什么
追问链：问 → 顺手的答案 → 能分开 A、B 的事实（来源｜时点）→ 新的问 → … → 落地的事实
关键数字：数值｜单位｜对象｜时点｜口径｜来源｜发布日期
量级：这条原因能解释多少价格变动
对手：以这个价格做反方向的是谁
判断：支持 / 有冲突 / 未解决，带"因为"
改变判断的条件：出现什么就推翻（能量化就量化）
可观察推论：哪天、哪个数据应出现什么
```

## 3. 取数地图：七类问题各看什么、去哪看

每类问题先回答"先看"里的几项，快速档通常到这里就够。深度档按以下顺序往下追：能翻转结论的证据 → 能区分两条路径的证据 → 影响损益的参数 → 背景。

常用来源：
- **收益率**：美国财政部每日收益率；日本财务省国债收益率（通常下一营业日上午公布前一日数据）；中债收益率曲线。
- **政策定价**：CME FedWatch、点阵图、OIS；中国货币网 FR007 利率互换。
- **持仓和期限溢价**：CFTC（周二数据，周五公布）、纽约联储 ACM 期限溢价。
- **买家**：美联储 H.4.1、TIC 月报；日本银行持有国债数据、日本证券业协会投资者买卖统计；中债登、上清所托管数据。

### ① 汇率异动：是政策重估、头寸调整，还是持续的资金需求？

**先看**
- 同一时段两国 2 年期或 OIS 利差，以及央行会议、重要数据的发布时刻。利差变化的方向比利差水平更有解释力。利差动得小而汇率动得大，就要追加流量和持仓证据，不能直接认定是平仓。
- CFTC 投机净头寸、1 个月隐含波动率、风险逆转。拥挤加波动跳升提示平仓风险；隐含波动突破过去一年高位时，风险上升。
- 最近两个可能改变方向的事件，以及会改变判断的数值。

**往下追**
- 名义利差、实际利差和预期政策差，分别支持哪一边。
- 组合投资、直接投资、银行和官方，谁是最近边际变化最大的流量。
- 经常账户的构成。初次收入顺差如果大部分留在海外再投资，不会带来本币买盘。
- 风险厌恶时，这个货币是融资货币、避险货币还是高 beta 货币。
- 政策按预期落地，汇率却反向走，说明已被计价，或者隐含假设错了。
- 全球美元融资压力：交叉货币基差、外汇掉期隐含美元利率、央行互换额度用量。

**分市场**
- **日元**：美日利差对汇率的解释力目前处在什么阶段。套息规模和杠杆的代理指标：CFTC、日本散户保证金头寸、BIS 估算。由美国利率上升引发的风险事件里，日元可能不升。居民海外资产在日元贬值时，是稳定器还是放大器。
- **美元**：美元"微笑"的哪一端在主导，是美国强增长还是全球避险。看相对增长、实际利差和避险需求是否共振。美国政策本身成为冲击源时，美元可能不再避险。
- **人民币**：利差的作用是否被顺差、管制和中间价抵消。分别看中间价、CFETS 篮子、在岸离岸价差和远期点各说明什么。出口商结汇和居民购汇的触发汇率在哪。

**常见误判**：看到汇率和利差同时动，就认定是利差驱动，没看先后顺序和幅度是否匹配。

### ② 外汇干预与制度：是临时逆风操作、可信承诺，还是制度在变？

**先看**
- 当局所处阶段：口头警告、询价，还是实际干预。看措辞升级的顺序和询价报道，只写阶段和依据，不写概率。财务省强调"过度波动"时，速度通常比水平更关键。
- 能马上动用的弹药。外汇储备里的存款可以直接用，证券要先卖出或回购。
- 利差预期是否配合干预方向。这是干预效果的重要变量，但不是转向的必要条件。规模、流动性和可信度也要看。

**往下追**
- 汇率制度：自由浮动、管理浮动、区间还是盯住。
- 干预目标：逆风操作、守某个水平，还是只压波动。
- 三元悖论里，当局牺牲哪一个。
- 政策可信度来自什么。
- 短期外债与可动用储备之比。
- 哪个可观察阈值会迫使政策转向。
- 政策跳空会不会越过止损。

**分市场**
- **日元**：财务省是被水平、速度、波动还是政治压力触发。月末公布前，可以用日本银行当座存款预测与货币经纪商预测的差额推测干预金额，最终以财务省公布为准。
- **人民币**：逆周期因子、宏观审慎参数和国有大行交易，只有官方公告或多家权威媒体一致报道才算证据。

**常见误判**：把外储月度下降当作干预金额，外储变动里含估值和利息。干预当天汇率回落，就判定干预成功。

### ③ 主权债方向：长端变化来自预期短率，还是期限溢价？

判断的是同期限总回报，不是只预测降不降息。

**先看**
- 市场已计入的政策路径：下次会议和一年后的隐含利率，与央行自己的判断比。
  - 美元：OIS 或联邦基金期货。
  - 日元：OIS。
  - 人民币：FR007 利率互换，或 1 年期国债、同业存单与 7 天逆回购的差。人民币国债与政策利率之差还受税收和流动性影响。
  - 两年期收益率只能当诊断代理，不能当成加息或降息的次数。
- 2 年与 10 年的同期变动。美元可用 ACM 期限溢价；日元和人民币没有常用的官方估计，看 10−2、30−10 利差。曲线变动只能用来提出解释，还要补政策、发行、买家和资金的证据。
- 判断错了能扛多少：算盈亏平衡基点，和近一个月日均波动比。盈亏平衡小于一周的正常波动，说明缓冲很薄。

**往下追**
- 不同期限溢价模型之间差多少，结论是否只靠一个不可观测的估计。
- 久期加权净供给和拍卖日历。
- 谁是边际买家。
- 我判断的政策路径和市场差在哪次会议、多少基点。
- 扣完骑乘、融资、对冲和成本后，是否还高于现金或短券。
- 通胀与财政同时上行时，"增长弱就买债"会失效。
- 通胀由什么驱动：服务和工资推动的通胀更持久。
- 回购特殊利率、交割失败和季末窗口，可能让融资成本高过 carry。

**分市场**
- **美元**：点阵图、经济预测摘要和 OIS 在今年底、明年底差多少。联储当前更在意就业还是通胀。历史三次抛售：1994 年是加息速度意外，2013 年是沟通推高期限溢价，2022 年是通胀误判。判断当前更像哪一种。
- **日元**：加息、减购、沟通三件事分开看。减购影响长端，加息影响短端和汇率。日本银行对工资、通胀、汇率和金融稳定的权重在变。做空日债的负 carry 能扛多久。
- **人民币**：7 天逆回购是主要政策利率。DR007、R007、存单和存款利率能看出传导是否顺畅。人民银行的约束排序：增长、物价、汇率、银行息差、金融稳定。30 年期更受保险负债需求影响，10 年期更贴近增长和政策预期。

**常见误判**：预期降息就认定长债会涨。降息已被计入，或期限溢价在升时，长端可能不跌反升。

### ④ 曲线与期限：风险集中在哪一段，谁推动的？

**先看**
- 是短端带动还是长端带动。再看政策预期、期限溢价、供给和买家各起了多大作用。
- 最近几次拍卖的尾差和投标倍数，只在同券种、同期限之间比较。尾差扩大、倍数下降提示需求转弱，还要结合投标构成和发行后的价格核对。发行调整是可能的应对，不能断言它一定止跌。
- 谁在买、谁在减少买。传统买家撤退又没有新买家接手时，同样的供给也会压低价格。

**往下追**
- 这笔头寸实际表达的是什么：久期、曲线、通胀、跨国利差，还是 carry 加骑乘。和想表达的观点一致吗。
- 修正久期、凸性、DV01 和关键期限久期要核对。利率方向对了、曲线错了，会亏多少。
- 牛陡、熊陡、牛平、熊平，哪种最符合因果和风险预算。
- 期限利差在 3、5、10、20 年和同阶段窗口的分位，说明为什么选这个窗口。
- 哪个工具表达观点最纯。
- 压力期的流动性、波动和相关性按同时恶化来算。

**分市场**
- **美元**：季度再融资里，中长期券的增发幅度比发行总额更影响期限溢价。交易商获配比例高、回购利率偏高，说明做市商资产负债表紧。
- **日元**：20 年以上最受寿险需求和发行计划影响。日本银行到期不再投资的部分，就是市场要多吸收的净供给。还有收益率曲线控制留下的流动性后遗症。
- **人民币**：超长期特别国债和地方债的发行节奏。边际买家要分开看：保险、理财、公募、农商行、外资。

**常见误判**：只看发行总量不看买家；只看收益率高低，不看骑乘和融资后的实际收益。

### ⑤ 跨币种比较：统一记账币种以后，还剩多少优势？

**先看**
- 对冲后收益：取 3 个月远期点或对冲成本、两国短端利率、交叉货币基差，按第 5 节的现金流法计算。远期点已经抵消的那部分利差不是收益。
- 不对冲时，汇率动多少会吃掉优势：算汇率盈亏平衡，和过去一年的波动幅度比。
- 是否同期限、同风险。久期不同时，名义规模相等和 DV01 相等两种口径都列。DV01 相等只匹配一阶利率敏感度，凸性、曲线、基差和流动性风险要分别说明。

**往下追**
- 债券风险和汇率风险是否重复。站在本币投资者和外币投资者角度，结论有什么不同。
- 交叉货币基差：先确认报价约定和期限，再判断借美元是否变贵。
- 用边际资金转移定价，不用平均负债成本。
- 压力下收益率跳升、流动性折价和对冲失效会不会同时发生。carry 会不会在压力时反转。
- 多空的盈亏符号、名义本金和保证金要写清。
- 不做会损失什么，这个损失值不值得承担尾部风险。

**分市场**
- **美元**：外国投资者对冲后买美债，收益低于本币同期限债券时，会减少买入或降低对冲比例。
- **日元**：寿险和养老金的海外资产对冲率，会随利差和波动变化。

**常见误判**：用未对冲收益率直接比两国债券；把远期点和利差当成两份收益相加。

### ⑥ 银行账簿与配置约束：息差、经济价值、会计结果分别怎么走？

**先看**
- 边际资金成本。日元看无担保隔夜拆借和 1 年期日债；美元看 SOFR 和 3 个月或 1 年期美债；人民币看 DR007 和 1 年期同业存单。这些是市场参考，不是本行成本。
- 加久期后的利率风险：每 100 亿本币的 DV01，收益率上下 50、100 个基点时的市值变化。只给单位规模的数字，由风控对照限额。
- 风险权重、是否算优质流动性资产、按公允价值还是按摊余成本记账。不写本行比率。

**往下追**
- 存量存款在 1、3、6、12 个月的重定价节奏。
- 挂牌利率降 20 个基点，只作用于新增和到期重定价的那部分。要考虑存款占比、客户迁移和定期期限；用"全部负债立即下降"作情景时，要明示这是假设。
- 负债降 20 个基点，可接受的债券收益率不一定同步降 20 个基点，还受资本回报和 DV01 限额约束。
- 票息减负债成本后，还要扣资本、税、运营、套保和流动性成本。
- 贷款和存量按揭会不会同步重定价。
- 账户性质是配置盘、交易盘还是代客理财，会计分类会影响止盈止损行为。
- 长端下行来自期限溢价压缩、降息远期，还是配置需求。
- 各类机构的净买入按期限怎样分布。

**分市场**
- **美元**：缩表、准备金充裕度、隔夜逆回购和财政部现金账户怎样影响流动性。准备金接近充裕下限时，回购利率会跳。商业地产和私募信贷可能带来非线性的信用紧缩。
- **日元**：银行和寿险持有的日债有未实现亏损，它们既不愿卖出确认亏损，也难以增持。
- **人民币**：息差低、贷款弱时，银行更依赖买债，"资产荒"会制造债券需求。回购放量、杠杆上升时，监管一收紧，容易引发集中去杠杆。

**常见误判**：净利息收入改善就当作经济价值改善；用平均负债成本代替边际成本；以为按摊余成本记账，风险就消失了。

### ⑦ 财政与金融稳定：是财政风险重估、市场功能失灵，还是政策将出手？

长债下跌先分清三种传导：
- **财政风险重估**：长债和本币同跌，评级和财政预测恶化。
- **市场功能失灵**：买卖价差扩大，做市商资产负债表受限，市场抢现金。
- **政策干预**：央行或财政部出手的阈值和工具。

**先看**
- 历史上当局出手时的利率、汇率和市场功能指标，以及官方表态。写成可观察的阈值，比如价差扩大到多少、尾差多大。
- 谁在用杠杆持有长债，追加保证金时会卖什么。算出被强平前能承受多大的价格变动。来源是各国央行金融稳定报告和 CFTC 杠杆基金持仓。
- 发行计划、拍卖结果和评级动态。拍卖连续走弱，又伴随评级或财政预测恶化，是财政风险重估的信号。

**往下追**
- 财政扩张是挤出私人融资，还是改善名义收入和债务可持续性。
- 货币政策独立性是否受财政融资、银行损失或政治周期约束。
- 家庭、企业、银行、政府中，谁有期限错配或浮息再定价风险。
- 债务上限、预算和评级事件怎样进入尾部情景。
- 基准情景和政策失误情景，各写出时间线、工具和退出条件。

**分市场**
- **美元**：长端上行而美元下跌，是美元信用折价的信号。债务上限对短期国债、财政部现金余额和风险偏好的影响分阶段出现。
- **日元**：利率每升 1 个百分点，利息支出增加多少；财政对正常化的承受力。
- **人民币**：地方债、置换债和财政存款怎样改变流动性和供给。

**常见误判**：把长债下跌直接等同于财政危机。

## 4. 证据与口径

**三类标注**（只在底稿用，报告里用措辞区分）：
- **〔事实〕**：官方原文、实际成交或报价、统计数据、已核对的原文。
- **〔推断〕**：我自己的因果连接，要写出竞争解释。机构观点写明作者和日期，不当事实，也不叫"市场共识"。
- **〔缺口〕**：取不到的数据。机制可以继续解释，但依赖这条数据的确定归因或收益结论要撤回。缺口不能填零、中性或"已核实"。

**证据强弱**：
- **主证据**：央行、财政部和监管原文，官方统计和官方收益率曲线。
- **能撑判断但不能单独定案**：市场报价和模型，比如 OIS、期货、远期点、期权、CFTC、期限溢价模型，以及 BIS 和央行研究。用时写明口径和局限。
- **只当线索**：媒体转述、卖方摘要、搜索摘要、传闻。
- **追不到源头的**：不进结论。

**独立性三查**：来源独立、测量对象独立、时间窗独立。几家媒体转引同一份公告只算一份。两年期收益率和 OIS 反映的是同一个政策预期，也只算一份。

**时点纪律**：公布日、观察期和读取时刻分开记。日内事件用带时区的时刻。只有日期的同日材料，不能证明它在事件前就可得。历史重放用当时首次发布的数据，不用后来的修订值。

**数字核对**。进结论的每个数字都写全：数值、单位、对象、时点、口径、来源、发布日期。下面是踩过的坑：

1. **报价方向**：美元兑日元从 163.86 跌到 157.73，是美元跌 3.7%，日元涨 3.9%（163.86 ÷ 157.73 − 1）。160 到 152 是美元跌 5.00%、日元涨 5.26%。
2. **口径和时点**：盘中新券报价 3.115% 和财务省日终固定期限 3.097% 不能相减当日变动，也不能拿去和另一口径的 2 年期算利差。
3. **基点和百分点**：持有收入从 55 基点到 75 基点，是增加 20 个基点、相对增加约 36%，不是"36 个百分点"。
4. **年化和持有期**：简单年化 = 期间收益 × 365 ÷ 天数，外汇远期和货币市场常用 360，要写明用哪个。年化成本、持有期回报和到期收益率不能混减。
5. **到期收益率不是回报**：用它估 carry 要标"近似"。
6. **同券和换券**：活跃券切换会制造单日变动的错觉。
7. **拍卖口径**：投标倍数 = 竞争性投标额 ÷ 竞争性接受额。尾差 = 最低价格对应的收益率 − 平均收益率。只在同券种、同期限之间比。
8. **中间价、指数、报价商快照都不是可成交价**，不能据此宣称可获得回报。
9. **模型估计**：期限溢价、均衡汇率、盈亏平衡通胀都要写明模型和局限，只看方向和量级。
10. **分组和代理**：净利息收入 ÷ 总资产不等于银行披露的净息差。用不同分组时要交代样本差异。
11. **外储和干预**：外储月度变动含估值和利息，不等于干预额。干预金额以财务省月末公布为准。
12. **"史上首次/最高"**：回查完整序列，写清"自哪年以来"和用的是盘中还是收盘。

查不到就写"未查到可靠来源"，不倒推、不估填。PDF 提取的数字要对照原页。

## 5. 计算：先走现金流，再算数

计算一律跑代码，不心算。先写输入、时点、单位、符号和现金流再算，成本缺失不等于零。进报告的数字要实际运行过，保留原始输出，再和正文、图表逐项核对。只列公式、声称"已复算"不算完成。

**跨币种的现金流法**：以日元记账，即期 S 和远期 F 都按"日元/美元"报价。1 日元换成 1/S 美元，美元资产持有期回报为 r，到期按远期全部卖回，日元终值 = `(1+r)×F/S`，再减成本 c，得到对冲后净回报 `(1+r)×F/S−1−c`。不对冲时终值为 `(1+r)×S_end/S`；相对基线回报 b 持平的期末汇率为 `S×(1+b)/(1+r)`。远期点和利差不能相加；对冲和未对冲的结果不能混算。美元兑日元下跌 d 时，日元的涨幅是 `1/(1−d)−1`，一般不等于 d。逐笔票息、部分对冲和展期，要按实际现金流另算。

**三种核对，缺一不可**：
- **比例法与金额法**：同一结果用两种算法各算一次。
- **方向检查**：用两国同期限利率按利率平价反推远期，和实际远期比方向。外币利率高于记账币种利率时，远期应低于即期。方向不一致，或偏离超出基差能解释的范围（通常零点几个百分点以内），先查报价方向和利率是否放反。
- **独立复核**：重要研究由另一方用实际输入重算。两边错得一样不算验证。没有工具时，标"未独立复算"。

**边界**：
- 简算只用于判断量级。实际头寸、大幅变动、非平行曲线、含权工具、滚动对冲，或精度会改变选择时，要完整重定价。完整重定价已含期限缩短的影响，不再另加骑乘。
- 方案比较要用同一持有期、同一记账币种、明确的风险尺度，加一个现金或短券的基线。收益拆到实际来源：票息、价格、骑乘、汇兑或对冲、再投资，再扣融资、交易、展期、税费。成本缺失时，报已知部分或求盈亏平衡边界。
- 净利息收入、经济价值、会计损益、经济总回报要分别分析。保证金、跳空和流动性可能让中途的损失大于终点的损失。

**例程**（Python 3，无第三方库；代入本次实际输入，不要照抄示例结果）：

```python
from decimal import Decimal as D


def _d(*xs):
    return [D(str(x)) for x in xs]


def hedged_return(spot, forward, foreign_hpr_pct, cost_pct, baseline_pct):
    # spot/forward 均为"记账币种/外币"；外币期末全部现金流按同期限远期卖出
    s, f = _d(spot, forward)
    r, c, b = (x / 100 for x in _d(foreign_hpr_pct, cost_pct, baseline_pct))
    net = (1 + r) * f / s - 1 - c
    amount_per_100 = (D(100) / s) * (1 + r) * f - D(100) * c   # 金额法
    assert abs(net - (amount_per_100 / 100 - 1)) < D('1e-20')
    return {'net_pct': net * 100,
            'vs_baseline_pp': (net - b) * 100,
            'unhedged_break_even_spot': s * (1 + b) / (1 + r)}


def parity_forward_check(spot, forward, dom_rate_pct, for_rate_pct, days,
                         day_basis=360):
    # 方向独立检查：用两国同期限利率按利率平价反推远期，与实际远期比方向
    s, f = _d(spot, forward)
    t = D(days) / D(day_basis)
    rd, rf = (x / 100 for x in _d(dom_rate_pct, for_rate_pct))
    f_parity = s * (1 + rd * t) / (1 + rf * t)
    return {'parity_forward': f_parity,
            'gap_vs_parity_pct': (f / f_parity - 1) * 100,
            'direction_consistent': (f - s) * (f_parity - s) >= 0}


def duration_scenario(price, mod_duration, convexity, delta_y_bp,
                      coupon_amount, funding_amount, cost_amount,
                      baseline_hpr_pct):
    # 金额与初始价格同单位；收益率变动以基点输入；二阶近似，大变动或含权债要完整重定价
    p, dur, con, bp, coup, fund, cost, base = _d(
        price, mod_duration, convexity, delta_y_bp, coupon_amount,
        funding_amount, cost_amount, baseline_hpr_pct)
    dy = bp / 10000
    price_ret = -dur * dy + D('0.5') * con * dy * dy
    net = price_ret + (coup - fund - cost) / p
    end_value = p * (1 + price_ret) + coup - fund - cost
    assert abs(net - (end_value / p - 1)) < D('1e-20')
    return {'price_pct': price_ret * 100, 'net_pct': net * 100,
            'vs_baseline_pp': net * 100 - base}


def breakeven_bp(ytm_pct, funding_pct, days, mod_duration, day_basis=365):
    # 持有期 carry 能扛住多少基点的收益率上行（近似，未含骑乘与凸性）
    y, f, dur = _d(ytm_pct, funding_pct, mod_duration)
    carry_pct = (y - f) * D(days) / D(day_basis)
    return {'carry_pct': carry_pct, 'breakeven_bp': carry_pct / dur * 100}


def fx_move(begin, end):
    # 报价"本币/外币"（如 USD/JPY）从 begin 到 end：外币对本币涨跌与本币对外币涨跌不对称
    b, e = _d(begin, end)
    return {'quote_change_pct': (e / b - 1) * 100,
            'inverse_change_pct': (b / e - 1) * 100}


def auction_stats(comp_bid, comp_accepted, lowest_price_yield_pct,
                  average_yield_pct):
    # 投标倍数 = 竞争性投标额 ÷ 竞争性接受额；尾差 = 最低价格对应收益率 − 平均收益率
    bid, acc, lo, avg = _d(comp_bid, comp_accepted, lowest_price_yield_pct,
                           average_yield_pct)
    return {'bid_to_cover': bid / acc, 'tail_bp': (lo - avg) * 100}


def pct_rank(history, current):
    # 历史分位：(小于当前值的个数 + 0.5 × 等于的个数) ÷ 样本数；换窗口各算一次
    h = _d(*history)
    c = D(str(current))
    less = sum(1 for x in h if x < c)
    eq = sum(1 for x in h if x == c)
    return (D(less) + D('0.5') * eq) / D(len(h)) * 100
```

**验算记录**（合成算例，用于确认例程没坏）：
- `hedged_return(150, 147, 2.20, 0.10, 0.80)`：对冲后 0.056%，比基线少 0.744 个百分点；未对冲持平汇率 147.9452。
- `parity_forward_check(150, 147, 0.5, 4.5, 180)`：反推远期约 147.07，方向一致；把远期误写成 153 时会报方向不一致。
- `duration_scenario(100, 8, 70, bp, 2.0, 1.0, 0.1, 1.0)`：bp 取 −50、+25、+75 时，净回报分别为 4.9875%、−1.078125%、−4.903125%。
- `breakeven_bp(3.07, 1.00, 90, 8.5)`：约 6 个基点。
- `fx_move(160, 152)`：美元跌 5.00%，日元涨 5.2632%。
- `auction_stats(6538.5, 1989.6, 3.011, 2.995)`：倍数 3.2863，尾差 1.6 个基点（2026 年 9 月 1 日日本 10 年期拍卖）。

**例程之外的简算**：
- **金额折算与覆盖倍数**：日元金额 ÷ 汇率 = 美元金额，写明用的是均值汇率还是事件日汇率。覆盖倍数 = 能马上动用的资源 ÷ 单次消耗，不用外储总额算。
- **久期与 DV01**：价格变动 ≈ −修正久期 × Δy；DV01 ≈ 修正久期 × 市值 × 0.0001。拿不到久期时，平价债修正久期 ≈ [1 − (1 + y/2)^(−2n)] ÷ y。
- **持有期收益**：≈ 票息 + 骑乘 + 价格变动 − 融资。骑乘 ≈ 期限缩短后的收益率下降 × 缩短后的久期，前提是曲线不变。
- **实际利率**：名义利率 − 同期限通胀预期。不要拿一国的名义利率和另一国的实际利率比。

**完整计算的要点**（深度档按需选用，交付时附输入表、公式、中间值、未舍入结果、复算和适用限制）：
- **外汇 carry**：先选实现方式，是现货融资套息还是远期头寸，不要把利差和远期点重复相加。基差、资本管制和无本金交割远期会让利率平价失效。
- **实际汇率偏离**：实际汇率 = S × 外国价格 ÷ 本国价格。用不同基期、窗口和价格指数各算一次。均衡值会漂移，不能当三个月目标。
- **汇率对利差的 beta**：用滚动回归，名义利差、实际利差、预期政策利率分别跑。β 变号、置信区间跨零、样本外误差放大，就判定失效。相关不等于因果。
- **久期和凸性**：用完整现金流计算，收益率上下各移 1 个基点做中心差分复核。近似超出容差时只用完整定价。含权债、浮息债、通胀挂钩债要用专用定价。
- **持有期总回报**：HPR =（期末全价 − 期初全价 + 票息 + 再投资 − 融资 + 对冲结果 − 成本）÷ 期初全价，和现金基线比。
- **carry 与骑乘**：在曲线不变的假设下老化重定价，平价法和零息法各算一次。"曲线不变"只是归因基线，不是预测。
- **久期加权净供给**：发行 − 到期 − 回购 − 央行净购买，按期限桶分别列现金额和 DV01，和财政部计划对账。供给不等于价格影响。
- **盈亏平衡通胀**：名义收益率 − 实际收益率，其中含风险溢价和流动性差异，不能直接当成纯通胀预期。
- **情景分析**：只设本次决策真正需要的互斥情景，不填概率。压力情景里，跳空、基差、保证金和价差同时恶化。
- **银行负债重定价**：按时间桶算节省额。"全部立即重定价"和"只有到期部分重定价"分开算。新债净收益 = carry − 边际资金转移定价 − 资本、流动性、对冲、运营和税费。
- **久期缺口**：资产久期 −（负债 ÷ 资产）× 负债久期。经济价值和 12 个月净利息收入分别报。平移、变陡、变平和短端冲击都要做。
- **历史分位**：全窗口和同阶段窗口都报，并说明窗口为什么这么选。同一个 49.4 个基点的利差，近三年是 93.3% 分位，近十年是 55.2% 分位。样本少时只报不确定性。

## 6. 历史机制库：按机制选，不按结果挑

30 段案例来自精简包的来源卡，2026 年 9 月下旬核对过，其中 US13、CN09、CN11 只部分核对。

用法：
- **先选机制再看结果。** 写清触发因素、约束、仓位和起始价格为什么和今天相关，再选一个主案例加一个结局不同的对照案例。快速档最多用一句历史启发。找不到同机制的案例，就说明差异，继续用机制推演。
- **重建转折前的局面。** 写当时公开了什么、价格隐含了什么、还不知道什么。不能把后来才知道的事写成"市场当时必然知道"。
- **移植到今天。** 写两项关键相同点、两项关键不同点，以及这些差异会放大、削弱还是切断传导。
- **进报告的历史数字，回到原卡的官方来源核对。** 案例数量不是胜率。

格式：编号｜时间｜机制：关键事实 → 分叉 → 今天看什么。

**政策路径、期限溢价、长端**
- **US04**｜1994｜加息速度超预期比方向更伤人：一年加息 7 次共 300 个基点，11 月一次加 75 个基点，10 年期到 8.05% → 低波动时积累的杠杆久期被迫平仓 → 比较市场定价的路径和央行可能的速度。
- **US06**｜2001–03｜降息前长端已经先下：3 个月期从 5.69% 降到 1.74%，10 年期只从 5.14% 降到 5.07% → 2003 年 6 月只降 25 个基点（市场预期 50），8 月 10 年期升 145 个基点 → 先算长端已经下了多少；购债预期落空时，可能两个月升 100 个基点以上。
- **US07**｜2004–06｜加息 425 个基点，10 年期只升约 60 个基点，因为期限溢价下降加海外买盘 → 估算没有外资流入的话 10 年期会高 150 个基点 → 加息周期里看两年期是否已按路径定价，再看期限溢价和 TIC 海外净买入。
- **US08**｜2008–09｜10 年期分三段走：抢现金、通缩避险、政策购债。2009 年 3 月购债公告当天降 51 个基点，6 月回到 3.98% → 公告日以外大幅回升 → 公告后看购买开始后守不守得住，别追高。
- **US09**｜2013｜没有加息，沟通也能推高长端：10 年期从 2.03% 到 2.98%，主要来自期限溢价 → 9 月暂不缩减当天跌 17 个基点 → 减购或缩表要单独看期限溢价。
- **US12**｜2022｜一次通胀判断错误，久期损失以年计：加息到 4.25–4.5%，2 年期到 4.72% → 10 月 CPI 7.7% 低于预期，2 年期单日跌 27 个基点 → 起点收益率低时，票息缓冲不了上行。
- **US15**｜2023-10｜政策利率不动，10 年期碰到 5%，原因是供给和评级 → 借款预估和中长期券增发低于预期，12 月回到 3.79% → 期限溢价推动的上行，看财政部的发行公告。
- **JP12**｜2024-03｜退出负利率，日元反而更弱，4 月 29 日到 160.17 → 加息幅度小、指引偏鸽、购债不减，利差几乎没变 → 看加息后的实际利率、利差和指引。

- **CN08**｜2018｜降准推动利率债走牛，表外融资收缩让社融降到 9.8% → 降准的钱没补上资管新规压缩掉的部分 → 社融下滑而 10 年期下行时可以拿久期，信用下沉要等社融企稳。
- **CN09**｜2020｜没有加息，短端从 5 月下旬起，1 年期从 1.39% 升到 2.94% → 季度数据确认修复之前短端已经持续上行 → 政策利率不变而短端连续上行，就是宽松在退出。

## 7. 前台交付

### 7.1 声音

一位见过几轮周期的资金部负责人，在和交易员、风控同事推演一笔判断。

- **自信**：第一句给结论。证据够硬就直说，不够就直说卡在哪个数据、哪天公布，不层层加"可能"。
- **睿智**：多看一层，说出二阶后果。能用一句大白话点破的，不铺术语。
- **严谨**：关键数字带对象、时点、单位和报价方向。严谨体现在数字上，不体现在免责声明的数量上。
- **缜密**：推理链没有缝，读者跟着推一遍，找不到被跳过的台阶。

能证明到哪里就写到哪里。不用"铁律""必然"这类词，历史规律说成"历史上常见的路径"。

### 7.2 篇幅上限（硬约束，用工具数字数）

| 项目 | 快速 | 深度 |
|---|---|---|
| 正文 | 300–400 字 | 900–1,200 字 |
| 结构 | 3–4 段，不分章 | 2–3 章 |
| 图 | 1–2 张 | 1–2 张 |
| 表 | 最多 1 张 | 最多 1 张 |
| 附录 | 不放 | 最多 1 个 |
| 来源 | 随数字带在正文里 | 最多 10 条，合并同类 |

- 上限只管前台，后台照样查完、算完。
- 超字数时先合并重复论证，再删次要例子，最后删背景。有三样任何时候都不删：决定性证据、导致结论不同的口径、改变判断的条件。
- 数字优先搬进图表；图表里的数字不计入字数，也不在正文里重复。
- 写不满下限就停，不凑。写不满通常说明问题问的不是这一件事，这时去问用户。

### 7.3 快速：直接在对话里

三到四段，每段管一件事：
1. 给判断，并摆出这次最要紧的那个事实。
2. 给最短完整的解释：为什么是这个原因，不是别的。
3. 写这个判断的含义，读者据此能做什么判断。
4. 必要时才写：会改变判断的那一个条件。

简单的概念问题，一两句答完。配 1 到 2 张图，放在它解释的那句话旁边。对话里放不了图时，交一张文字简表。用户要保存或转发时，做成一页短网页，正文一字不加，计算和来源折叠起来。

### 7.4 深度：一页网页

动手前先加载 artifact-design 和 dataviz 两个技能。先把报告写完，再做页面。

页面结构：
1. **封面**：一句写明对象和判断的标题，一句大字判断，三个与主线直接相关的关键数字（各配一行说明），资料截止时点（含时区），一枚标签写判断的性质，比如"头寸修正，未成趋势""压力在期限溢价""对冲后不占优"。不写"买入""卖出"。
2. **导语**：第一句给判断，再摆出全篇要解开的那件事。入口按题挑，可以是一组看似矛盾的事实、一个反常数字、期限间的反差，或一个相似的历史场景。不要每份都用同一招。
3. **正文 2–3 章**：每章一个陈述式标题，带具体的货币、期限、机构或数字。主线那章最长。主线之外的发现压成一句话嵌进相关段落。
4. **结论**（见 7.5）。
5. **附录**：只在有复杂计算时放。
6. **注释与来源**：小字，官方原文和一手数据优先。

附录、来源、口径说明可以用 `<details>` 收起，折叠标题写人话。结论、关键数字和最缺的那条证据永远不折叠。页面不展开、不滚动时也要完整可读。

**专题报告**（如超长债、日元套息、美元融资）同样从后台追问长出骨架。封面配一张这个专题的地图，比如按期限分层的买家和供给，把最关键的一环用强调色标出。正文围绕此刻真正悬而未决的那件事展开。

### 7.5 结论和全篇写法

- **从这次最特殊的两三项差异写起，不从框架写起。** 比如某个期限偏离历史、某个买家的对冲后账本、某条 OIS 路径的偏离。能贴到十篇报告上的句子一律删掉，比如"市场情绪悲观，风险资产承压"。
- **结论正面回到导语摆出的那件事**：解开了没有，在哪个数字上解开，什么条件下会反过来。封面、导语、结论三处说的是同一件事。
- **留一个让步锚点**：写明我在什么数据或事件面前会改判，比如某条收益率线、某次拍卖倍数、某个时间窗。阈值要有依据，来自融资成本、历史范围或测算。
- **反例默认只在后台检验。** 只有足以推翻或明显削弱结论的那一条才写进正文，一两句话，放在它影响的那个判断旁边。不另起一节罗列风险。
- **问题藏起来，只留下问出来的东西。** 标题写要点或事实，用陈述语气。用事实接住上一节留下的张力，不写"那么问题来了"，不写问答体。结构跟着后台追问的顺序走，不按三问或任何固定章节排。
- **读完全文，读者应当清楚四件事**：价格为什么动、能不能持续、市场计入了多少、这个价位值不值。纯解释型问题，第四件改成"这对相关市场意味着什么"。
- **结尾**：不写下一步行动、跟踪清单或复查日期。用户要持续跟踪时，另外给一份，最多四到六组指标，每组写明变化后对应什么动作。

**范本学到的四点**（参考债市邦 2026-07-22、2026-09-22 两篇文章）：
- 把一条消息变成一个能回答的问题，问题里要包含现有解释说不通的地方。
- 资料要细到机构真正面对的选择：额度、杠杆、可投范围。机构有钱，不等于会买。
- 已观察到的净买入是事实，"为了排名"之类的动机是推断。
- 同一个位置要换窗口检验。范本的错误也要避开：分组混用不交代、代理口径冒充披露口径、无样本的"七成概率"。

### 7.6 中文写作

- **段落**：每段两三句，段首是断言。一段只做一件事：给事实、解释原因、算账、处理异议或说明限制。
- **句子**：长短交替，连续三句长度接近就改。
- **具体**：平均每 200 字至少一个可核查的数字、日期、机构或期限。不写"流动性明显恶化"，写"买卖价差从 0.5 个 tick 扩大到 1.4 个 tick"。
- **数字后面跟意义**：给出投标倍数，就说它说明了竞价的什么。
- **先讲机制，再给名词**：术语第一次出现时顺手解释，如"隔夜指数掉期（OIS）"。
- **报价和单位写准**：写"美元兑日元"还是"日元兑美元"，涨的是谁。基点和百分点、年化和持有期每次都分清。
- **禁用词**：因此、从而、进而、值得注意、需要指出、换句话说、综上所述、总体而言、不难看出、毋庸置疑、显著、极大地、本质上、某种程度上、赋能、抓手、底层逻辑、闭环、链条、范式、重塑。强调词是证据的占位符，要用就换成它代表的那个数。
- **禁用句式**："这不是 X，而是 Y"（直接说 Y）；用破折号制造停顿；"关键在于："式的冒号揭示；加粗标签开头；等式句和箭头链；结尾升华；同义词轮换；"本文从几个维度分析"之类的章节预告。

### 7.7 图表

每张图只回答一个问题，标题就是一句结论。图放在它解释的那句话旁边。

| 想说明什么 | 用什么图 |
|---|---|
| 一个数字怎么来的、谁贡献了多少 | 分解图（瀑布或分段条形），正负用同色深浅区分 |
| 几种假设下各是什么结果 | 情景表：行是假设，列是两三个关键结果，3–5 行，不填概率 |
| 哪个期限在动 | 分组条形：各期限在两个窗口的变动；或曲线前后两条线 |
| 长端里政策预期和期限溢价各占多少 | 堆叠条形或两条线，注明模型 |
| 汇率和利差是否同步 | 共享时间轴的上下两张小图，或变动散点；不用双纵轴 |
| 事件当天发生了什么 | 日内折线，标出公告、数据和干预的实际时刻 |
| 仓位是否拥挤 | 净头寸柱状序列，标出多年高位 |
| 买家谁增谁减 | 发散条形 |
| 供给压在哪段、拍卖强弱 | 期限桶净供给柱；同券种的尾差和倍数序列 |
| 对冲以后还剩多少 | 瀑布：外币收益 → 对冲拖累 → 成本 → 对冲后收益，再和本币收益并排 |
| 要动多少才吃掉优势、判断错了亏多少 | 尺子（现价、阈值、历史区间）；收益率变动对净回报的曲线 |
| 位置算高还是低 | 横向条形：多个窗口的分位 |
| 市场计入的路径和央行差在哪 | 阶梯线 |

画法规矩：
- 只标起点、终点、极值和故事所在的点。
- 一个强调色，其余用灰。
- 图下一行小字写来源、口径和观察期。
- 不做 3D、饼图、双纵轴、彩虹配色。没有原始数据时，不伪造精确数值；存疑的部分用虚线。

视觉规范按 artifact-design 和 dataviz 两个技能执行，本技能只加三条：
- 用系统中文字体栈，数字用等宽数字。
- 正文约 17px，行宽不超过约 38 个汉字，全文加粗不超过五处。
- 中文和英文、数字之间留半角空格，金额写明币种。

### 7.8 交付前自查（不展示）

1. **数字**：每个数字回底稿核一遍；正文、图、注释、附录里的同一个数完全一致；跨币种结果做过方向检查。
2. **篇幅**：用工具数过字数、章数、图表数，没有超出上限。
3. **反模板**：遮住货币和期限只看标题，能不能认出是哪次行情？只读标题，能不能串起全篇要点？和上一份同类报告比，入口和结构是否一样？
4. **推理**：预设核对过了吗？关键词有定义吗？支持主线的证据，对手解释是否同样能解释？量级对得上吗？每个关键判断经得住三次"凭什么"吗？
5. **收口**：封面、导语、结论是否一致？有没有让步锚点？
6. **越界**：有没有出现"对我们"一节、用户投资范围之外的方案、虚构的本行参数，或"日本市场美元债"？
7. **后台词**：有没有漏出三问、路线、编号、底稿标注这类后台词？有没有设问腔或问答体？结尾有没有跟踪清单？
8. **页面**：实际打开看过桌面宽度、手机宽度和深色模式；图表标签不重叠，页面不横向滚动。

## 8. 留档与复盘

重要判断都要留档：资料截止时点、原判断、当时定价、可观察推论、后来的结果、对错和原因。更新判断时，只解释改变了什么，保留原判断，不回改历史；没有新证据，就写没有变化。

**复盘五问**：信息错了吗？模型错了吗？执行错了吗？风控错了吗？还是运气？"运气"要继续拆，拆到能控制的因素为止。同时回看可观察推论：哪些兑现了，没兑现的当初凭什么被认为成立。积累到足够多记录后，才用 Brier 分数和对数得分做校准，按时间扩展窗口，不随机打乱；样本少时只报不确定性，不宣称胜率。

试用中出过的错，要记住：
- 公式写对了，不代表输出的数字对。试用里出现过远期方向用反、情景表数字算错，加了实际运行代码和三种核对后才全部改对。
- 表格数字和公式对不上时，以实际运行结果为准。

本框架还没有检验过：实时取数，全部案例的事实真伪，滚动对冲和复杂债定价；也没有样本外的预测记录。真实任务里的对错，才是它好不好用的证据。
